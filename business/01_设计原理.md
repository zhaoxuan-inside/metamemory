## 一、产品公理（全产品有效）

0. **信息即服务（总纲）**：一个组织（个人/团队/公司——都是域）拥有的信息是"**我的信息**"；从中派生"**我需要的信息**"（意图）与"**我能提供的信息**"（供给/画像）。基础层 = 组织每个域的"我的信息"（域主权 = 数据主权 + 算力主权）；上层应用 = 对两类派生的挖掘服务——知道自己免费，知晓世界收费（ADR 13）。
0a. **核心层只做两件事：接收信息与查询信息**（架构裁定，见《产品设计》§十五）：接收 = 一切信息进系统的唯一入口（add 事件流 + 写侧治理）；查询 = 一切信息出系统的唯一出口（search + context）。网络即查询的对外延伸——搜自己域内、搜他人（经授权/公开层）、搜公共信息是同一个 search 经裁决器返回的不同结果集，无独立网络 API。增值产品（意图面板/简报/L4 生成发布/撮合/信誉/权益）全部属业务层，**只经 add/search 消费核心层，技术强制（import-linter 白名单）而非纪律**。遗忘的目标是给整个网络减负：衰减/灰色遗忘/压缩是检索空间的治理——把全网信息聚焦到最近被关注的事情上，检索空间越小，五路融合与全网搜索的质量与成本越好。
1. **只有一种主体**：系统中只有"域"一种实体；角色差异一律转化为属性与信誉。
2. **一切功能回答"用户能知道什么"**：管理、授权、确认退居幕后。
3. **视野不是权限，是知晓边界**：对内全知、对外可知；档位是记忆的属性，裁决发生在读取时。
4. **升档需确认，降档即生效；派生不越权（三不越权）**：① 信息量不越权（脱敏与抽象度是手段）；② 血缘单向（公开的是投影，不是源）；③ 生命周期不越权（源失效 → 派生级联）。L4 = 域对"我能提供的信息"的**发布投影**（生成/发布分离），是派生不越权的合法发布例外。
5. **一条确认链**：个人与组织的意图确认同构，全网只有一条。
6. **视野无特殊通道**：任何读取路径必过统一裁决器。
7. **写免费，读收费；关于自己永远免费**；撮合方向性原则（偏好出域只走 L4 抽象通道）。

## 二、业务能力的设计原理

### 2.1 提取原理：语义价值不在字面里

- **提取的对象是命题，不是句子**：句子可能埋三个命题也可能全是寒暄；关键词没有归属、时间、断言方向；摘要是压缩，命题才是可校验、可更新、可冲突消解的资产单位。字面（原文）只是**证据**，命题才是**资产**。
- **原子化**：一句话拆成 N 条原子断言——只有原子才能逐条校验忠实、逐条更新、逐条消解冲突、在 token 预算内精确择优；断言之间的关系不装在断言里（装了就不再原子），由边承接。
- **双时态**：每条事实带 valid_from/valid_to（世界时间）+ learned_at（系统时间）——"知识更新"与"时点查询"是**数据模型能力而非 prompt 能力**；更新 = 关闭旧原子 + supersedes 指针，不删除。
- **无引文不记忆**（公理 4）：每条断言锚定原文 span——"记得对不对"从感觉问题变成**可机器检验的门**。
- **代价不对称**（公理 2）：一次"胡说"不可撤回，一次"没想起"可补救——结构化层 precision 优先宁缺毋滥，原文层全量保底托住漏记下限。这是全体系最重要的取舍。
- **提取与推理分离**（公理 3）：提取通道只许搬运用户真说过的（S2）；一切归纳、画像、模式走 S4 派生——带血缘、降置信、标注"我推测"。搬运与推断混在一步，产出的就是高置信的垃圾。
- **价值是后验的**（公理 1）：记忆的价值在唤起时兑现，不在写入时确定——架构必须让判错可逆（原文保底）。
- **巩固是选择性的（新增，Sun et al. 2023 Nat Neurosci）**：无管控的向上搬运会过拟合并伤害泛化——新皮层只吸收"利于泛化的可预测成分"，不可预测细节留在原始层。落点：结构化层只收"复用面跨情境"的命题，判据见"巩固收益门"（2.2-五）。
- **读取即再巩固（新增，B3 2026 再巩固/BDNF 通路分离实验）**：检索命中不是纯读——存在一个短暂"可改写窗口"，窗口内允许 supersedes 重写与衰减重置；窗口外回到只读。落点：读后更新与强度重置在"窗口"内治理，而非任意时刻（2.2-三）。
- **通用知识不入库（delta 与全集）**：可再生知识零边际价值；定律本身不记，"域与定律的连接"（立场、约定）必须记。
- **单元切分是统计过程，不是工程常数（新增，Saffran/Aslin/Newport 1996 Science）**：连续输入流中"哪里是一个记忆单元"缺少显式边界时，切分依据是**邻接转移概率**（婴儿 2 分钟连续音节即可完成切词）——切分先于提取、是写侧第一决策；切分参数属演化参数（约束 13），证据 span 原样保底。
- **抽象是渐进的、以条目为本（新增，Tomasello 2000 TiCS）**：抽象范畴/规则从**具体条目的重复使用**中逐步涌现（item-based），不存在一次性"总结出抽象规则"的写入；落点：派生分层——先固化稳定复用的具体结论，schema 级抽象须挂到具体复用证据之上（与巩固收益门同规，裁定 R9）。

### 2.2 认知科学原理（可工程化）

| 原理 | 内容 | 映射 |
|---|---|---|
| **互补学习系统（CLS）** | 海马体快速学习情景，新皮层慢速归纳语义 | 快写入情景层（不阻塞）+ 离线巩固归纳语义——双进程架构的学理依据 |
| **巩固收益门（Sun 2023）** | 巩固以"泛化收益"为准则；可预测成分才向上迁移，防过拟合 | 结构化层收入门：只固化"跨情境复用可预测"的原子；不可预测细节留在原始层（原文/情景）。判据：复用频次（重复 ≥ 阈值） × 跨情境度（≥2 个独立情境复现） × 泛化 holdout 增益 |
| **海马索引理论** | 新皮层存内容，海马体只存关联索引；检索靠索引扩散 | 原文层存内容，图谱存索引；检索沿实体关联扩散 |
| **遗忘曲线（Ebbinghaus）** | 强度随时间衰减，重复使用重置 | `strength = f(重复,检索,情感) × e^(-λ·Δt)`；**Δt 在"检索命中"时重置（再巩固窗口，B3）** |
| **编码特异性（Tulving）** | 提取成功取决于线索与编码情境匹配 | 存储必须保留情境（来源/话题/时间/参与者）——情境触发检索路的依据；检索意图三分（哲学背书：SEP《Memory》episodicity 三判据）：事实问答 / 时点定位 / 自传检索，三类读取走不同的质量分层 |
| **读取即再巩固窗口（新，B3 2026）** | 记忆在检索后有一段活性窗口，可被改写或消退（reconsolidation ≠ 恒保留） | **读后更新窗口**：检索命中 → 记录 `last_recall_at` 并消耗窗口（默认 72h，窗口参数可调）——窗口内允许 supersedes 重写与衰减重置；窗口外再写视为新的派生 |

> 与旧版本差异裁定：旧 2.2 未包含"巩固选择性"与"再巩固窗口"；本稿补入并消除"派生 = 全量吸收"的潜在歧义（详见 §八 裁定记录）。

### 2.6 语言科学原理（新增，可工程化；证据 `research/papers/ling/`）

| 原理 | 内容 | 映射 |
|---|---|---|
| **图灵上界（Turing 1936）** | 符号处理在形式上存在不可判定的判定问题（Entscheidungsproblem 无解；停机不可知）——任何"全自动判定"必有覆盖不到的输入 | 2.4 "自动判定不了的绝不静默处理"的**形式化学理上限**：自动裁决链每一级必须实现**显式 abstain** 并转人工，禁止"默认接受"兜底（约束 15；裁定 R8） |
| **形式装置与语法性独立（Chomsky 1957）** | 结构合法性独立于语义可接受性与统计平滑（"colorless green ideas sleep furiously"）；深层结构差异需要显式结构描述，表层统计混合无法替代 | 命题原子化的语言学必要性与词性/句法分析的层级位置；**"读起来合理/生成流畅 ≠ 结构合式"**——置信模型不得把流畅度当校验通过 |
| **统计切分（Saffran 1996）** | 单元边界出现在转移概率取谷处；低样本（2 分钟）即可 | add 入口切分/切段的其一量化信号；切分参数入演化闭环（约束 13；裁定 R7） |
| **渐进抽象（Tomasello 2000）** | 早期语言能力以具体词项为本，抽象范畴在复用中分批涌现 | 派生分级与巩固收益门的**时间维度表达**：复用证据先行、抽象后行（裁定 R9） |
| **表示层可探测（Hewitt & Manning 2019；Tenney et al. 2019）** | 句法/词法/语义信息以线性可读形式嵌在分布式表示中，沿"词法→句法→语义"梯度分布；且模型常**动态回溯修正低层决定** | ① 探测式对账（probe 集合）作为读侧召回之外的中间质量探针进演化闭环；② 前置层输出为**可推翻的软信号**（约束 14；裁定 R6） |
| **确定性转移系统（Nivre 2008）** | 复杂分析可归约为显式状态机（transition system）+ 特征判别：行为可审计、可重放、可增量 | 写侧决策/冲突治理的**骨架表达方式**：显式转移系统，与"决策骨架确定性"（R4）同规 |
| **子词单元（Sennrich 2016 BPE）** | 高频相邻单元融合产出子词单元，解决开放词表（所有 token 可编码） | tokenizer 选型与 OOV 策略的技术背书（选型档）；产品词汇/绰号等"域内开放词"须子词可达、保召回 |
| **分布式表示 + 离散索引双载体（Mikolov 2013 / Pennington 2014；HippoRAG 同构）** | 相似性在向量空间里，结构与多跳在图索引里——两种载体互补非替代 | 原文层向量索引 + 图谱边索引的双载体的语言学背书；置信/检索不共器 |

### 2.3 关系原理：联成网络才是记忆

- 单条事实回答不了跨会话问题——向量检索对多跳**结构性失败**，图扩散一步召回（HippoRAG 实证，多跳 QA 提升最高 20%）；
- **八类边**（实体/时序/情境/替代/语义/因果/派生/冲突）各自语义、建立算子、时机与置信不同——**无依据不建边**（每条边携带可解释依据）；
- **虚假关联是已证风险**：错误链接把噪声放大进推理（A-Mem 对抗集反输）——防线 = LLM/NLI 确认门槛 + 边置信参与排序 + 用户纠错剪边；
- **过连与欠连都致病**：度数上限 + 剪枝（过连）；连通分量监控（欠连报警）；
- **边也是记忆对象**：边可见性 = min(两端点)——"关联即信息"；端点删除 → 边同步删。

### 2.4 治理原理：让错误可发现、可纠正、不扩散

- **置信度是乘式不是主观分**：`置信 = 来源级别（S1-S4）× 抽取分 × 时间衰减`，三因子独立演化、独立可解释；自报分经人工校准集映射；
- **冲突是三类判定 + 三条路径**：时间演进（确定性规则关闭旧原子，自动）/ 粒度差异（并存）/ 真矛盾（挂起人裁）——自动判定不了的绝不静默处理；
- **低置信隔离**：可检索带标注，不进 L4/简报/撮合；哲学背书：记忆系统的错误检索（confabulation）是常态而非异常——低置信不是"待删除对象"，而是"隔离观察对象"（SEP《Memory》Klein 2015 分型）。
- **未检索 ≠ 未存储（新增，沉默 engram 原理）**：记忆可能确实存在但检索通路失灵（神经科学"silient engram"实证）——"检索质量不足"与"存储体量不足"混为一谈会误判系统。落点：**双指标治理**——① 存储完备率（写入侧，原文层覆盖）；② 检索召回率（读取侧，基准题集对账，LongMemEval/LoCoMo）分别设阈值分别报警；二者恶化对应不同处置（补灌派生 vs 调索引/排序参数）。
- **血缘回溯**：纠错沿派生链向下游传播——错误以派生形式复活是最大的信任事故。
- **反馈只改参数，不改内容与边界**：纠错走治理（血缘+审计）；参数（排序/衰减/配比）走演化闭环（三级：微调自动生效/策略批量/管道过门禁）；视野、授权、免费边界不可被反馈触碰。

### 2.5 工程原理（框架与实现）

| 原理 | 内容 |
|---|---|
| **推理阶梯四级** | 确定性规则 → 经典 NLP → 嵌入式小模型（进程内）→ 外部强模型（经网关）；LLM 是最后手段，每处强模型调用登记"低阶梯为何不行" |
| **语义理解前置化** | 第 0 层零 LLM 分类器级联（安全/PII/分类路由/查重短路）——理解前置 + 语义缓存，参考 vLLM Semantic Router；提取与更新两决策分离、查重前置，参考 mem0 |
| **信息即服务分层** | **三层两仓**：框架层（驱动与基建，开源）→ 核心层（接收 + 查询两动词族，开源，配额封顶可全本地行使）→ 业务层（增值产品，**闭源**，只经两动词族消费，import-linter 强制）——"关于自己的知晓"全部在开源两层内完整可行 |
| **任务式 + 流水线** | 长程请求任务式受理；局部并行整体受控（图执行）；资源优先保已入任务（准入背压） |
| **全模块无状态** | 状态只在持久层；节点可中断，任务不中断（租约 + 活跃游标重放 + 调用缓存幂等重放） |
| **数据契约** | 步骤/模型间传版本化数据文档，下游按字段映射（JSONPath）配置抽取——不传对象不 import 类型 |
| **处理容器** | 方法五段执行：配置提取 → 封装对象 → 容器内操作 → 拍平写回 output map → 异常策略处置；五参全 map |
| **防腐层** | 一切外部组件经本地封装访问，业务禁止 import 外部 SDK——入向契约化、出向封装化，边界全受控 |
| **组件可插拔 + 允许缺失** | 9 槽位 Store 族 + 部署档位（full/lite/minimal）；缺失按降级矩阵退化（Redis 缺席 → 内存缓存） |
| **写侧决策可学习（新，Memory-R1）** | 写侧 CRUD 决策（{ADD, UPDATE, DELETE, NOOP} + 检索后过滤）可由少量标注（实测 152 QA pairs）经 RL（PPO/GRPO）学习，3B–14B 泛化 | 决策骨架保持确定性（规则优先）；学习差量只走演化闭环回流：仅优化参数与阈值，不改决策骨架（与"反馈只改参数"同规） |
| **框架职责封闭** | 框架九项职责（注册/编排/受理/执行环境/重启不中断/监控/升级/组件配置/编排配置）+ 负空间——接任何业务不改框架 |
| **双时态 LWW 同步** | 本地↔云同步起步用 learned_at + 内容 hash 判胜负，同实体同谓词走 supersedes 链；CRDT 待冲突率数据 |

## 三、设计约束（从公理推导，全项目有效，精选）

1. 一种实体：新功能先问"这是域的什么属性/记忆/目录"；
2. 数据模型一次定型 ≠ 功能一次交付（按基础层→派生层→服务层切片）；
3. 视野无特殊通道：新增读取方 = 新增查询者上下文类型，不是绕行；
4. 派生不越权：任何生成物视野取 min（L4 发布投影为唯一合法例外，四道防线补偿）；
5. 只治理域内记忆：跨域不做删除传播；
6. 业务层只消费不侵入：业务层只经 add/search 消费核心层（ADR 16 技术强制，原"扩展层只消费不侵入"）；其行为以记忆事件写入域记忆，核心层不感知其业务语义；
7. 投影不另建系统：公开条目、L4 抽象、信誉视图都是记忆的投影；
8. 推理分层对齐计费：内置不暴露 API、可选独立计费、业务推理不实现；
9. 反馈只改参数不改边界；个性化参数按域隔离，优化动作全部留痕；
10. **巩固收益门（新增）**：任何向结构化层/S4 的固化动作必须携带"为何利于泛化"的量化信号（复用频次 × 跨情境度 × holdout 增益三者过门），否则停留在原文层；无协同收益的自动派生视为过拟合来源，禁止静默入库；
11. **再巩固窗口（新增）**：读命中后的 supersedes/衰减重置只在窗口内（默认 72h）行使，窗口与窗口外两种写路径受不同门禁；
12. **双指标毕竟分离（新增）**：存储完备率与检索召回率是两个独立治理指标，不得用其中一个伪装另一个。
13. **单元切分可演化（新增，Saffran 1996）**：切分粒度/边界是演化参数而非出厂常数；切分依据须可归因（统计信号可给出），证据 span 原样保底——切分损失可逆。
14. **前置层软信号（新增，Tenney et al. 2019）**：前置分类器/小模型输出（路由/查重分类/分级）携带置信且可被下游更强的裁决推翻并回写——前置追求便宜，不追求终审；**硬裁决只有两处：安全/PII 门（fail-closed，只能收紧不可推翻）与确认链**（置信不确定时按低置信隔离处置）。
15. **显式 abstain（新增，Turing 1936）**：自动裁决链每一级必须有"弃权"出口，弃权即挂起人裁；不可判定处禁止默认值兜底（默认值 = 静默处理）。
16. **公开层目的闸（新增，反向检查 G1 提级）**：L4/L5 检索面按授权目的过滤——发布者设定允许目的集、查询者声明目的、裁决器匹配放行；组织域目的限定（§11.2 同构）全场景必做；目的字段是裁决谓词不是记录项。

## 七、公理的可证伪校验（防自我循环裁决）

公理与决策记录互为裁判会形成自我循环（"冲突时以裁定为准"没有外部校验点）。补强如下：

### 7.1 公理的失效信号（任一触发 → 启动公理复审，不是自动推翻）

| 公理 | 失效信号（可观测） | 复审动作 |
|---|---|---|
| 信息即服务（公理 0） | 免费层 COGS 实测 > 收入期望 × 设定比例；用户大幅绕开派生层只用原文层 | 重估三层切分粒度 |
| 一种实体（公理 1） | 组织域场景出现 ≥3 处为个人域写特殊分支 | 评估是否承认二型 |
| 视野即知晓边界（公理 3） | 裁决器组合用例无法覆盖新增读取方 | 检查档位光谱完备性 |
| 升降档铁律（公理 4） | L4 事后否决率/纠错率超阈值（否决 ≈ 生成机制系统性失灵） | 重估生成/发布分离的自动化比重 |
| 确认链唯一（公理 5） | 出现只能靠异步 LLM 判定的归并（确定性/嵌入均失效） | 评估级联第四级，而非破坏唯一性 |
| 巩固收益门（约束 10，Sun 2023） | 结构化层派生条目"复用率≈0"占比超阈值（沉淀 ≈ 过拟合） | 重估收益门判据，收紧结构化层入门 |
| 再巩固窗口（约束 11，B3 2026） | 窗口内重写后用户纠错率显著高于窗口外（窗口机制误开放） | 重估窗口时长与门禁 |
| 双指标治理（约束 12，沉默 engram） | 存储完备率达标但召回率持续低下（以存储量伪装检索质量） | 索引/排序与派生灌入的资源配置复审 |
| 单元切分可演化（约束 13，Saffran 1996） | 基准题集上"边界切错导致命中/丢失"的失败例占比超阈值 | 重估切分参数与 span 保全策略（演化闭环） |
| 前置层软信号（约束 14，Tenney 2019） | 前置分类器被下游推翻/用户纠错率超阈值（前置层事实上终审化） | 重算前置阈值；确认为硬裁决路径的须走确认链 |
| 显式 abstain（约束 15，Turing 1936） | 出现未经显式弃权就通过（专家默许兜底）入路由/治理的隐藏默认路径 | 补弃权出口并审计；路径级回写门禁 |

### 7.2 外部校验点（不依赖体系内裁定）

1. **基准对账**：LongMemEval/LoCoMo 分数为唯一外部质量锚——内部指标全优但基准测退化 = 体系判错，回写决策（原理 §四已列坐标，此处赋予裁决地位）；
2. **红队对账**：视野/授权/注入三条线每季度红队演练一份输入，结果即公理失效证据的合法来源；
3. **用户纠错率**：纠错是最高优先级信号，用户纠错率突升 = 置信/质量模型系统性失准，触发演化参数复审。

### 7.3 程序约束

失效信号触发"公理复审会"（Baseline ADR 召回），产出三种结论之一：公理成立（补防御）/ 公理修订（新 ADR）/ 公理废弃（回写下游全部引用文档）。任何失效信号永不静默处理，与冲突治理同规。

## 八、裁定记录（v0.5 冲突消解）

| # | 冲突点 | 旧行为 | 裁定 | 依据 |
|---|---|---|---|---|
| R1 | "S4 派生"被读作"全量向上搬运" vs CLS 现代结论"无管控搬运致过拟合" | 未明确门槛 | 派生必过**巩固收益门**（复用频次 × 跨情境度 × holdout 增益）；不过门停在原文层 | Sun et al. 2023："unregulated neocortical memory transfer can cause overfitting" |
| R2 | `strength` 公式的 Δt 未定义何时重置 vs 再巩固窗口实验 | 只有"重复使用重置"一句 | 明确 **Δt 在检索命中即重置**；supersedes 重写仅在**读后窗口**（默认 72h）内行使 | Dai et al. 2026：巩固/再巩固通路分子级可分离 |
| R3 | "存储量"与"检索质量"隐含混用（原§四 Engram 行只提混合读取） | 单一口径监控 | 拆为**双指标**：存储完备率（写侧）与检索召回率（读侧，基准对账）；恶化不得互相伪装 | Bai et al. 2026 沉默 engram："存在但检索不出" |
| R4 | "反馈只改参数"未覆盖"写侧决策本身可否学习" | 未涵盖 | 决策**骨架**由确定性规则固化不可被反馈改写；决策的参数/阈值经演化闭环学习（如 RL）| Memory-R1（152 QA pairs × PPO/GRPO）|
| R5 | 读取场景无意图分层，哲学上 episodicity 判据可直接映射 | 未分层 | 检索意图三分（事实问答 / 时点定位 / 自传检索）为读取路的**质量分层门**，非新增 API | SEP《Memory》episodicity 三判据 |
