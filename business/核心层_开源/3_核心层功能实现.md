## 一、业务的数据资产（一切能力的输入与产物）

| 资产 | 结构 | 角色 |
|---|---|---|
| **原文片段**（情境容器） | 原文 + 来源 + 说话人 + 话题 + 时间 | **证据**——全量保底，永不删除；提取与压缩的原料 |
| **语义原子**（记忆条目） | {主体, 谓词, 客体} + 双时态（valid_from/valid_to + learned_at）+ supersedes + 引文 span + 类型（偏好/事实/承诺/事件）+ 置信分 + 来源 S1-S4 + 视野 + 强度 | **资产**——可校验、可更新、可消解、可预算择优的最小记忆单位 |
| **模式原子**（S4 派生） | 模式陈述 + 跨期计数 + 血缘回连 | 压缩产物——"本月提到记忆 17 次" |
| **关联边**（八类） | 类型 + 端点 + 权重 + 置信 + **依据** + 双时态 | **关系**——单条事实是笔记，联成网络才是记忆 |
| **画像 / 意图** | 画像字段（S4）/ 意图（状态机 + 三旋钮） | 派生资产与特殊记忆 |

**数据流总纲**：原文 —（提取）→ 原子 —（关系）→ 网络 —（压缩）→ 模式 —（唤起）→ 表达。

## 三、提取设计：怎么提取数据、提取哪些信号

### 3.1 提取什么：原子命题

一句话拆成 N 条原子断言：`{主体, 断言内容(一件事), 类型(偏好/事实/承诺/事件), 时间, 引文 span, 置信分}`。为什么原子化：只有原子才能逐条校验忠实（引文能否推出）、逐条更新（"搬北京"只覆盖一条）、逐条消解冲突、token 预算内精确择优；断言之间的关系不装在断言里（装了就不再原子），由边承接（§五）。

### 3.2 提取哪些信号：值得度五维 + 反面清单

| 信号 | 来源信号（可计算） | 判定方式 |
|---|---|---|
| **投入度** | 主动陈述 > 被动提及；重复次数；强调词（"一定""记住"）；情绪强度；主动转回话题 | 规则信号 + 小模型 |
| **具体性** | 实体个数、时间词、数值、专名密度 | 结构特征统计 |
| **时效性** | 时限词（"周五前"）；意图动词（"要""打算"） | 词表 + 小模型 |
| **可复用性** | 四唤起场景命中预判（回答用户问题/主动告知/任务信息量/可检索） | 小模型按场景作答 |
| **新颖性** | 与既有原子嵌入相似度 top-k | 相似 = **更新信号**非新记忆 |

**反面清单**（命中直接折叠）：寒暄；过程性对话；纯第三方信息；**通用知识**（主体非域内实体且可再生——定律不记，"客户不认可该定律"必须记：立场不可再生）。

### 3.3 两级提取

```
原文流
 ⓪ 单元切分（segment，写侧第一决策）：对话轮/文档段/事件边界统一切分——
    HanLP 话题级联 + 邻接转移概率/复用统计（可归因信号，随语料演化）；span 原样保底，切分可逆
 ① 轻量选取器：五维信号打分 + 反面清单 → 值得度预判（便宜，全量过）
 ② 深提取器（仅值得的段落，强模型）：
    命题化（一句 → N 原子）→ 归属还原 → 时间解析（dateparser + 相对时间锚定）
    → 类型判定（决定价值曲线与衰减路径）→ 引文定位 → 置信自报（校准集映射）
```

**分形态提取信号**（归一层先行）：

| 形态 | 形态特有信号 | 算子差异 |
|---|---|---|
| 口语对话 | ASR 置信度、说话人轮次、VAD 停顿（切分边界）、代词密度 | 归一先行（标点/ITN/语气词/同音代词）；没还原"谁对谁说了什么"不得命题化 |
| 文档 | 标题层级、表格结构、条款类型（合同 → 义务/金额/日期；纪要 → 决议/责任人） | schema 路由挂提取 schema；表格逐行 × 表头 → 原子 |
| 结构化数据 | 无提取——字段即事实 | 事件化映射（日历 → "某日与某人开会"），S3 |
| 外部信息 | 与意图/偏好画像嵌入相关度、来源权威度 | **不进用户实体图谱**；摘要入库"替你读过"，保留原文链接 |

### 3.4 忠实闸门（无引文不记忆）

引文锚定失败 → 拒绝入库转复核（不静默）；NLI 两级校验（小模型批量，边界带升级 LLM）；置信自报经人工校准集映射（自报分不可信）；置信模型不采"生成流畅度"信号——结构合法性独立于语义可接受性（设计原理 §2.6 Chomsky 条）。

### 3.5 注入隔离产物规则（pre.gate 的下游承接）

预理解层判定为疑似注入的段落，其提取产物执行强制降级（纵深防御的提取侧落点，技术实现见《产品的技术选型》§2.3）：

1. 置信强制 ≤ S3 下限，无论价值分多高；
2. 视野默认 L1，禁止任何自动升档（含 L4 管道候选资格剥夺）；
3. 不得进入简报/画像/模式归纳输入；
4. 段落与产物带注入疑标记，用户在时间线视图可见并可人工复判（复判为正常 → 解除标记升 S2）。

## 四、压缩设计：怎么压缩数据

**压缩 = 密度分层，不是删除**：原文（全量）→ 原子（精选）→ 模式（归纳），体积递减、密度递增，证据永远可回溯。

| 压缩机制 | 时机 | 信号 / 判据 | 算子 |
|---|---|---|---|
| **四态路由** | 写入时 | 五维价值分 ≥ 阈值 → 提取；有信息量不到门槛 → 折叠（情境容器，可全文/语义 grep 捞回）；无断言 → 留原文；**分类把握不足 → abstain 弃权待复核**（挂 pipeline_review_queue 带原因码，禁默认落置） | 路由判定；不对称公理：胡说不可撤回、没想起可补救——结构化层宁缺毋滥，原文层托底 |
| **模式归纳** | 巩固期 | 同主题原子簇、跨期计数变化、共同召回；**必过巩固收益门**（复用频次 × 跨情境度 × holdout 增益）——**派生分级**（R9）：具体结论过标准门，schema 级抽象过严格门且显式引用复用证据（item-based 渐进抽象，Tomasello 2000） | 聚类 → 模式原子（S4，血缘回连，降置信标"我推测"）→ 原条目 archived |
| **强度衰减** | 持续 | `strength = f(重复, 检索频次, 情感) × e^(-λ·Δt)`，λ 域级个性化；**Δt 于检索命中重置 + 72h 再巩固窗口**（supersedes 重写与衰减重置仅在窗口内行使，约束 11） | 惰性 + 每日批量刷新 |
| **灰色遗忘** | 巩固期 | 长期零唤起零引用 | 降权（排序惩罚），数据保留可恢复——价值后验修正 |
| **到期归档** | 意图时效 | 有效期到期 | 退出发现索引 + 血缘下游级联撤下 |
| **硬遗忘** | 合规 | 用户遗忘权请求 | 物理删除 + 血缘级联 + 审计（唯一真删除） |

通用知识不入库（delta 与全集）：可再生知识零边际价值；防重复靠不入库，不靠事后跨域归一。

## 五、关系设计：怎么建立数据之间的关系

### 5.1 八类关系（每类独立算子与置信）

| # | 边 | 语义 | 建立算子 | 时机 | 置信 |
|---|---|---|---|---|---|
| 1 | 实体边 | 谈论同一实体 | 实体统一后自动互连（权重 1.0） | 写入时 | 确定性 |
| 2 | 时序边 | 时间接近/先后 | 时间窗建边，权重 `exp(-Δt/σ)` | 写入时 | 确定性 |
| 3 | 情境边 | 同一会话/文档 | 同 episode 成员自动互连 | 写入时 | 确定性 |
| 4 | 替代边 supersedes | 新事实使旧事实失效 | 同实体+同谓词 → 关闭旧原子 valid_to | 写入时 | 确定性 |
| 5 | 语义边 | 主题/含义相关 | 嵌入 top-k 候选 → NLI/共现过滤 → 边界带 LLM 判定 | 异步 | 廉价 + 一次 LLM |
| 6 | 因果边 | 因为 A 所以 B | 因果连词规则初筛 → 边界带 LLM；用户明示升 S1 | 异步 | S4 低置信 |
| 7 | 派生边（血缘） | 模式 ← 成员事实 | 模式归纳产生 | 巩固期 | S4 |
| 8 | 冲突边 | 真矛盾挂起 | 冲突检测产生，双向隔离 | 检测时 | 人裁 |

**无依据不建边**：每条边携带依据（共享实体/引文/规则/LLM 判定记录）——"模型觉得像"的边不允许存在。

### 5.2 关系的前提：实体统一（最硬的一关）

| 级 | 算子 | 判据 |
|---|---|---|
| ① 别名表 | 规范化字符串 + pg_trgm 模糊索引 | 精确/近形命中 |
| ② 嵌入相似 | 同类型实体嵌入余弦 | ~0.85（挡语义误并） |
| ③ LLM 语境裁决 | 称呼 + 上下文 + 候选描述 → match/new/**abstain** | abstain = 新建（重复可救，错并难救） |

**三信号加权**（同形不同人）："信号不是实体是什么，而是它在谁旁边"——`score = 名字相似 × 0.5 + 图邻居共现重叠 × 0.3 + 时间接近 × 0.2`；低于阈值新建实体；漏配（单元素簇兜底）与过并（度数上限）双向监控。

**谓词归一**：词表精确 → 嵌入相似归一 → 词表外新谓词 LLM 登记——谓词不归一，图碎成同义边森林。

### 5.3 边的治理

边可见性 = min(两端点)——"关联即信息"；端点硬删 → 边同步删；用户可在图谱视图看见并纠正关系（关联透明是信任的一部分）。

## 六、治理设计：数据的正确性规则

| 规则 | 算子 |
|---|---|
| 置信度 = 来源权重（S1>S2>S3>S4）× 抽取分 × `e^(-λ·Δt)`；自报分经校准集映射 | 三因子独立演化 |
| 冲突三分法 + **abstain 出口** | 时间演进 → supersedes（72h 窗口内，自动）；粒度差异 → 并存（自动）；真矛盾 → 挂起（人裁，挂起期不参与 L4/打分/简报）；**任何自动级判不了 → 显式弃权挂人裁，无默认值分支（约束 15/R8）** |
| 低置信隔离 | `conf ≥ 阈值` 统一谓词——可检索带标注，不进 L4/简报/撮合 |
| 血缘回溯 | 纠错（最高优先级）→ 修正/降级 + BFS 下游 stale → recompute 管道 → 错误不扩散 |
| 记忆体检 | 周任务扫低置信/真矛盾/长期未验证 → 待确认清单随周刊 |

## 七、读路径设计：数据怎么被唤起与表达（同步，不经编排）

- **五路信号**：语义（pgvector HNSW）/ 全文（FTS）/ 图谱（递归 CTE 扩散 + 权重衰减）/ 时间（区间查询）/ 情境（episode + 情境边整体复活——编码特异性）；
- **检索意图三分**（R5）：事实问答 / 时点定位 / 自传检索三类 quality profile——召回深度/精排规模/逐条 NLI 复核按意图分层，是 search 参数不是新 API；
- **公开层目的闸**（约束 16）：公开面（L4/L5）结果按"发布者允许目的集 × 查询者声明目的"过滤，不匹配不入结果集——裁决器谓词，业务层无旁路；
- **双指标**：存储完备率（写侧覆盖率）与检索召回率（基准对账）分开报警（R3）——读取侧的恶化禁止拿"再灌数据"伪装；
- **融合**：RRF 初融 → reranker 精排 → `× 置信 × 强度` 加权；权重按域个性化；
- **视野**：统一过 VisionArbiter（查询者上下文裁剪，过滤前不做业务加工）；
- **表达**：`融合分 × 置信 × 强度` 排序，Token 预算内择优装入，`{memory_id, span}` 溯源，置信分级透出（"你明确说过" vs "我推测的"）；**不知道就说不知道**；
- **原文层语义 grep**：折叠/留原文内容语义可达（显式检索场景），标注"原文片段（未经结构化）"。

|---|---|---|
| ingest | accept → normalize → **segment** → gate → dedupe(switch) → select → extract(fork) → anchor → verify(fork/join) → score(四态) → organize → done(wait 复核) | 对话流/导入/代理阅读/业务层事件 |
| consolidate | 强度刷新 → 压缩候选 → 模式归纳 → 图清理 | 每日 cron |
| recompute | stale 收集 → **loop** 逐下游重算 → 清除 | 纠错/硬删事件 |

## 九、工程形态（决策 A14）
