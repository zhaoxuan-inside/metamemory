## 一、商业模式与变现

### 1.1 三条经济原则

1. **写免费，读收费**：发布意图、发布供给（被世界知晓）永远免费——发布是网络的养料；
2. **关于自己，永远免费**：知道自己（记忆、变化、纠错、遗忘）不设墙——信任地基不可变现；
3. **C 端免费接收，B 端付费知晓**：钱从想知晓别人的人身上来，流向被知晓的人。

### 1.2 计费三层（公理"信息即服务"的直接推论，ADR 13）

| 层 | 内容 | 收费 |
|---|---|---|
| 基础层——组织"我的信息" | 原文层全量 + 语义层组织 | 本地版免费（**算力域自担，"写免费"的经济学前提**）；云端按**容量 + 提取量**配额封顶（配额即免费层 COGS 上界） |
| 派生层——挖掘与发布 | "我需要的信息"（意图）、"我能提供的信息"（供给/画像）的挖掘与发布 | **永远免费** |
| 服务层——网络挖掘 | 公开检索 / 情报流 / 握手 / 景气指数 | 按量与订阅收费 |

### 1.3 边界全貌表

| 知晓方向 | 免费 | 付费/权益 |
|---|---|---|
| 知道自己（个人域） | 晨报周刊完整、唤起无限、画像、纠错遗忘、完整时间线与图谱、溯源深链 | 生效意图发现位数（免费 3 个，配额限发现服务不限意图本身） |
| 知道自己（组织域） | 基础记忆容量、员工助手基础版 | SaaS：座位费 × 记忆容量 × 检索量 |
| 被知晓（发布） | **一律免费**：意图发布、供给上架、L4 抽象生成 | 无（这是原则，不是档位） |
| 知晓域内 | 基础协作 | 角色视野细化、审计日志（组织 SaaS 内含） |
| 知晓世界（情报） | C 端机会情报免费接收 | B 端：情报流订阅（按流数/新鲜度分档）、景气指数 |
| 知晓深度（握手解锁） | — | B 端付握手费/成交佣金；C 端反向获得分成或抵扣 |

### 1.4 收入结构

- **工具期**：个人 Pro 订阅（深度知晓）、组织 SaaS（座位/容量/检索）、Memory/Intent API 计费、私有化部署 License；
- **生态期**：情报流订阅、握手费、成交佣金（Take Rate）、景气指数订阅；
- **权益闭环**：C 端成交 → 平台抽佣 → 用户拿分成 → 抵扣个人 Pro——用户从"被 monetize 的对象"变成"网络的股东"，隐私承诺因此可以光明正大兑现。

### 1.5 变现的技术闸门

计量闸门（能力开关 + 配额计数 + 按量计价）三种机制实现为横切闸门点，业务代码不写"免费还是付费"判断；计量维度含检索次数 / token 用量 / 存储字节 / 提取条数 / 记忆容量（配额即 COGS 上界的执行件）。实现见《产品的技术选型》§4.12。

## 二、冷启动体系总览

撮合类网络的经典难题是双边冷启动。解法分两层：

| 层 | 解法 | 归属 |
|---|---|---|
| **结构层**：网络冷启动 | 一次接入、双边激活——每个域发布需求（想被找到）时，其供给自动进入 L5 公开层 | 产品结构（见《产品设计》§7.2），运营无需额外动作 |
| **运营层**：信任冷启动 + 习惯冷启动 | 开源本地引擎 + 开发者生态 | 本文核心 |

产品结构解决了"网络有没有两端"，运营要解决更前置的两问：

- **信任冷启动**：隐私产品的死亡之问——"凭什么把一生的记忆交给你？"
- **习惯冷启动**：记忆产品的死穴——"不喂就没价值"，如何让用户先喂起来？

## 三、开源战略

### 3.1 开源解决的三种冷启动

| 冷启动类型 | 原方案 | 开源补强 |
|---|---|---|
| 网络冷启动 | 一次接入、双边激活（产品结构内建） | 开发者生态成为节点蓄水池 |
| **信任冷启动** | 隐私承诺（说） | **代码即承诺（可验证）**：本地开源引擎让"数据不出设备"成为任何人可审计的事实 |
| **习惯冷启动** | 初识对话（只解决第一公里） | 用户在零成本、无网、无云环境先把记忆层用起来——习惯养成后，上云是升级不是迁移 |

核心逻辑：**安全感驱动使用 → 使用产生记忆 → 记忆产生粘性**。

### 3.2 开源分层：开什么，不开什么

| 层 | 开源？ | 理由 |
|---|---|---|
| 记忆引擎核心（本地完整版，**含 L4 抽象生成**——挖掘"我能提供的信息"属域主权能力，ADR 13） | ✅ | 域主权的完整行使依赖本地可生成；"记忆不出设备"承诺因此完备 |
| 数据格式与授权协议 | ✅ 开放标准 | 数据可携带权的终极形态；抢占行业标准位 |
| CLI / 桌面端 / SDK | ✅ | 开发者工具链，Agent 框架即插即用 |
| 撮合网络（匹配引擎/握手清算）、信誉聚合、景气指数 | ❌ 云端 | 网络资产，价值来自全网规模 |

**关键洞察：开源之后，护城河不是代码。** 别人可以 fork 引擎，但 fork 不走三样东西：

1. 全网意图密度（撮合匹配质量随规模复利）；
2. 演进中的分面词表（通用语言，社区共建）；
3. 信誉档案的历史积累（行为记忆无法移植）。

**代码是获客工具，网络才是资产**——开源是把"基础设施人人可持有"与"网络价值独此一家"分开的手术刀。

### 3.3 与产品架构的统一：本地域 = 域的端侧形态

开源不是新产品线，是**同一个域的另一种存在位置**（策划书 11.7 端侧演进的提前落地）：

- 本地引擎跑在用户设备上，L1-L5 视野、授权三元组、意图确认链**在本地全部生效**——机制全网只有一套；
- 部署成本 = **lite 档**：SQLite + 内存缓存 + 嵌入式推理，单容器/单二进制，`docker run` / `pip install` 即用（《产品的技术选型》决策 #21）——"零成本先用起来"的工程兑现；
- 上云是可选的、增量的：只有用户愿意被发现的 L4/L5 层需要云端；
- 同一套数据格式，本地 → 云**零迁移**（兑现"终局一次定型"原则）。

## 四、养成路径（漏斗即商业模式）

```
开源本地引擎        →   云同步          →   发布 L4/L5        →   撮合成交
（习惯：本地分身、      （便利：多端同步、    （意愿：被发现的       （收益：分成/
 本地简报、本地Agent）   云端Agent、推送）     收益开始显现）         抵扣 Pro）
```

每一步都有独立的升级动力，没有一步是"求用户"——**收益驱动的自愿上云**：

| 漏斗层 | 用户动机 | 运营抓手 |
|---|---|---|
| 下载开源引擎 | 免费拥有本地分身；隐私安全感 | GitHub / Hacker News / 掘金场景化内容 |
| 开启云同步 | 多端同步、云端 Agent 接入、简报推送 | 无缝迁移体验，零导入成本 |
| 发布 L4/L5 | 被发现带来的实际机会 | 首批撮合成功案例的传播 |
| 撮合成交 | 分成 / 抵扣 Pro | 权益到账的即时反馈 |

## 五、开发者生态运营

1. **即插即用**：SDK + MCP Server 形态，任何支持 MCP 的 Agent 零成本接入；
2. **社区双重身份**：开发者社区 = 撮合网络的需求侧蓄水池 + 供给侧预备队——每个集成 SDK 的 Agent 产品，其用户都是未来的域；
3. **PLG 主张**："关于自己的知晓永远免费"与开源本地引擎互为证明——免费不是套路，是可以拿走源码自建的。

## 六、词表社区治理（产品机制的运营化）

产品侧内置"开放标签回流"机制（见《产品设计》§9.2）。运营侧升级为**社区提案制**：

- 高频新标签由社区提案 → 审核 → 吸收进官方词表；
- 行业包由头部供给域与社区共建；
- 意义：开发者社区不只是用户，是**分类法这门通用语言的共建者**——词表将来是全行业的，治理权是社区忠诚度的来源。

## 七、撮合类目扩张节奏

**分类法跟着密度走，绝不先建空城。**

- **第一年只打三类**（需求高频、供给易结构化）：
  1. 招聘（岗位即天然分面，需求最标准化）；
  2. 采购 / 服务外包（B2B 服务商付费意愿最强）；
  3. 商务合作（渠道、联名、供应——供给反推流的主场）。
- 其余行业只开"条件流"、不自建词表；密度达标再建行业包；
- 每个类目的开城标准：需求发布密度 × 供给响应率 × 握手转化率 三指标达阈值。

## 八、增长与传播

1. **认知卡片裂变**：周刊"你的变化"一键生成分享卡（只分享抽象洞察，永不出示具体记忆）→"我的 AI 分身比我更懂我"晒图 → 扫码进入初识对话 → Day 1 晨报闭环；
2. **"我的本地分身"传播**：开源社区的晒配置、晒本地简报内容——极客圈层的自传播素材；
3. **Day 1 仪式感**的口碑化："第一天，我记住了你的 7 件事。这 3 件，你可能自己都没意识到。"——天然社交货币；
4. **景气指数公关**：定期发布行业需求景气月报，确立"需求风向标"的行业心智，反向为情报台获客。

## 九、风险与边界

| 风险 | 应对 |
|---|---|
| 开源版被 fork 做成竞争网络 | 护城河在网络资产（意图密度/词表/信誉档案），不在代码；持续加大社区与标准投入，让"标准随我们演进" |
| 开源版与云版边界模糊，伤害付费 | 纪律：凡是"关于自己的知晓"与"本地能力"一律开源免费；凡是"网络效应产物"（撮合/抽象生成/指数）一律云端。边界即承诺，写进开源 README |
| 社区治理被滥用（刷标签、词表污染） | 提案制 + 信誉档案准入（策划书 9.3 的信誉机制复用到社区治理） |
| 冷启动期情报流稀薄伤体验 | 密度不足的类目不开放情报流（只开条件流），宁缺毋滥 |
| 免费层提取成本失控 | lite 档算力域自担 + 云端容量/提取量配额封顶（ADR 13，已裁决） |
