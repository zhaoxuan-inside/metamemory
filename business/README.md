# MetaMemory 文档族 · 分层总纲

> 版本 v1.0 · 2026-09-24 · 本档是文档族的**地图与开源边界裁定**。

## 一、三层定义（系统设计说明）

| 层 | 职责 | 开源 | 仓库 |
|---|---|---|---|
| **1. 框架层** | 驱动整个项目 + 基础功能：任务编排/崩溃恢复/流量组织/监控告警/组件升级/处理容器/数据契约/Store 接口族/防腐层——**零业务** | ✅ 开源 | `metamemory-framework`（与核心层同仓两包） |
| **2. 核心层** | 信息的输入与产出：add（接收信息）+ search（查询信息）两动词族 + 视野裁决/审计/计量横切 + 记忆引擎九能力域 | ✅ 开源 | `metamemory`（lite 档即协议实现，本地全闭环） |
| **3. 业务层** | 增值业务：意图面板/认知简报/L4 发布/撮合网络/需求情报台/景气指数/信誉档案/权益分成 | ❌ **闭源** | `metamemory-x`（独立仓库，import 单向 x → core → framework） |

**边界公理**：用户"关于自己的知晓"（记忆/唤起/画像/纠错/遗忘/本地 Agent 接入）在开源两层内**完整可行**——隐私承诺可被任何人审计；网络效应产物（撮合/情报/信誉/指数）云端独占（《运营推广策略》§3.2，ADR 21）。

## 四、分层维护纪律

1. **跨层改动**：先改 02（产品裁定）→ 01（原理/约束）→ 各层文档传导，反向检查报告随大版本更新；
2. **层内改动**：只动本层文档 + 在本档文档地图核对归属；跨层引用一律指向本地图谱；
3. **开源边界纪律**：凡新增能力先问层归属——"关于自己的知晓"进核心层（必须可开源），网络效应进业务层（闭源）；import-linter 三条规则（x→core→framework 单向、业务禁直连 Store、步骤禁 import 上游类型）CI 阻断。
