# 01 候选方案原理对比（_02_principle）

> 状态：confirmed　更新：2026-09-27
> 来源：`business/01_设计原理.md` v0.7（原理与证据链权威）、`business/03_与Mem0的对比分析.md` v0.2。本文按 SOP 模板重排为"原理问题 → 候选方案 → 原理级对比 → 结论"。

## 1. 要解决的原理问题

从 _01 验收标准提炼，需技术原理支撑的核心问题五组：

- P1 记忆的资产单位与更新机制（验收：跨会话不失忆、可纠错、可时点查询）；
- P2 多跳关联的检索机制（验收：图谱浏览、情境唤起）；
- P3 写入质量的可信机制（验收：无引文不记忆、事实与推测不混淆）；
- P4 受理与读取的时延形态（验收：快通道 <100ms、唤起 P99 <300ms）；
- P5 不可判定输入的处置（验收：判不了不静默、挂人裁）。

## 2. 候选方案清单

| 编号 | 方案 | 一句话原理 |
|---|---|---|
| S1 | 全量原文 + 向量 RAG | 切块嵌入，检索时相似度召回，prompt 组装 |
| S2 | 命题原子 + 双时态图谱（本项目） | 原子断言为资产、supersedes 关闭不删除、八类边建网、五路融合 |
| S3 | 单遍 ADD-only + 检索期软重排（Mem0 v3） | 累积不删，衰减重排 0.3×–1.5× 隐式压制旧事实 |

## 3. 逐方案原理阐述

### S1 全量原文 + 向量 RAG

- **原理**：文档切块 → 嵌入向量 → ANN 检索 → 塞入上下文。
- **能力边界**：单跳事实尚可；多跳问题**结构性失败**（向量只能拉近邻，HippoRAG 实证图扩散一步召回，多跳 QA 提升最高 20%）；无更新语义——旧事实与新事实并存且无失效标记；"记得对不对"不可机器检验。
- **风险与对策**：上下文爆炸（大海捞针）→ 预算组装；幻觉不可溯 → 本项目不采用为骨干，仅借其原文块语义 grep 作折叠内容的捞回通道。

### S2 命题原子 + 双时态图谱（采纳）

- **原理**：① 提取对象是命题不是句子，原子化才能逐条校验/更新/消解；② 双时态（世界时间 valid_from/to + 系统时间 learned_at）让"知识更新"与"时点查询"成为**数据模型能力**：更新=关闭旧原子+supersedes 指针，不删除；③ 原文层存内容、图谱存索引（海马索引理论），检索沿实体关联图扩散；④ 置信=来源级别×抽取分×时间衰减，三因子独立可解释；⑤ 快通道原文层同步落底（互补学习系统 CLS：快写情景 + 慢归纳语义）。
- **能力边界**：提取质量依赖强模型（忠实率受六指标 CI 门禁约束）；写路径长（任务式受理，"我记住了什么"不即时——快通道兜底）；图谱边质量决定多跳上限（虚假关联已证风险 → LLM/NLI 确认门槛 + 边置信参与排序 + 用户纠错剪边）。
- **风险与对策**：过拟合派生 → 巩固收益门（R1/Sun 2023）；检索失灵被误判为未存储 → 双指标分治（R3）；不可判定 → 显式 abstain（R8，见 S4 对比）。

### S3 单遍 ADD-only + 检索期软重排（Mem0 v3）

- **原理**：只增不改，旧事实靠检索时衰减软重排（0.3×–1.5×）隐式压制。
- **能力边界**：表象"不删除"与 S2 相同，但**裁决机制不同**：v3 无失效语义——旧事实在时点查询中无法证明"当时为真、现已失效"；软重排是检索期行为，与写入期的确定性关闭不可互换（Mem0 对比 §二-2）。
- **风险与对策**：过期事实污染时点查询 → 本项目用写时双时态 supersedes 显式关闭。

### S4 全自动闭环 vs 主干自动 + 显式 abstain（采纳后者）

- **原理**：Turing 1936 形式上存在不可判定的判定问题——任何"全自动判定"必有覆盖不到的输入；符号系统的结构合法性独立于语义流畅度（Chomsky 1957，"流畅 ≠ 合式"）。
- **能力边界**：全自动必然在某处静默兜底；每级显式弃权转人工才可审计。
- **风险与对策**：弃权率突升=上游级联失灵/输入漂移 → 弃权率作为观测指标告警（框架 A15）。

## 4. 原理级对比

| 维度 | S1 向量 RAG | S2 原子+双时态图谱 | S3 ADD-only 软重排 | 说明 |
|---|---|---|---|---|
| 多跳检索 | 结构性失败 | 图扩散一步召回 | 同 S1 | HippoRAG 实证 |
| 时点查询/知识更新 | 无失效语义 | 双时态+supersedes 显式关闭 | 软重排隐式压制 | S2/S3 的本质分叉 |
| 写入质量可信 | 依赖调用方 prompt | 引文锚定+NLI 闸门（服务属性） | 无闸门 | 代价=受理非即时 |
| 读时成本 | 全量塞入，贵 | 索引命中，便宜（写时付费） | 中 | Zep/Engram 实证 |
| 一致性/正确性 | 无治理 | 置信三因子+冲突三分法+血缘回溯 | 无级联 | 血缘不可下放 |
| 复杂度（实现/运维） | 最低 | 高（管道+治理） | 低 | 换取质量属性 |
| 可演化性 | 参数少 | 决策骨架确定、参数可学习（Memory-R1） | 排序参数 | 反馈只改参数不改骨架（R4） |

## 5. 结论

- **采纳 S2 为主干**，S1 的语义 grep 降级为原文层捞回通道，S3 教训吸收为"不删除表象相同、机制不同"的对比坐标；不可判定处置采纳 S4（显式 abstain）。
- 受理形态采纳**任务式 + 快通道兜底**（与 Mem0 同步形态是协议级差异点①，方向经评估正确：忠实率成为服务属性）。
- search 采纳**服务端裁决**（key 即查询者）——协议级唯一本质分叉②；manage 拆 correct/visibility/authz/forget 四子动词（差异点③）。
- 不确定项（进入 _03/演化闭环）：巩固收益门阈值、切分参数、前置分类阈值均为提案值；中文基准集待补。
