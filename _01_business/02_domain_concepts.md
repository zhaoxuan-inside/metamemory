# 02 领域概念表（_01_business）

> 状态：confirmed　更新：2026-09-27
> 本表是 `_09_project_dict.json` 的词条来源；一物一名，禁用别名以代码统一命名为准。

## 1. 主体与授权

| 概念 | 定义 | 与其他概念的关系 |
|---|---|---|
| 域 Domain | 系统唯一容器实体：个人域=单成员域的事实称呼，组织实例=组织租户；域无类型字段 | 一切信息的归属单位；承载视野/授权/意图 |
| 成员 Membership | 域 × 个人域的关系记录，角色是成员身上的数据标签（JSONB + json-logic 规则） | 角色即属性，零代码路径；审批人由角色规则数据决定 |
| 租户 Tenant | 数据主权硬边界（个人域 1:1 租户；组织实例 = 组织租户），RLS 根 | 框架层概念，与域正交（A5） |
| 视野 Visibility | 知晓边界档位：L1 私有 / L2 授权 / L3 域内 / L3·D 定向 / L4 抽象 / L5 公开——六档=五级+定向变体（N1） | 读取时裁决的属性，非权限开关 |
| 授权三元组 AuthorizationRecord | 授权 = 视野档位 × 使用目的 × 时效；粒度（条目/主题域/时间窗）、TTL、状态、允许目的集 | 裁决器谓词来源；撤回幂等、到期自动收回 |
| 允许目的集 PurposeScope | 发布侧声明的允许使用目的集合（如求职撮合 ✓ / 广告营销 ✗） | 公开层目的闸的裁决谓词（约束 16，G1） |
| Agent 接入 AgentConnection | 授权 Agent 的接入记录：视野档位、授权引用、审计开关 | Agent 只能提议意图；key scope 映射视野档位 |

## 2. 记忆资产

| 概念 | 定义 | 与其他概念的关系 |
|---|---|---|
| 原文片段 MemoryEpisode | 情境容器（原文层）：原文+来源+说话人+话题+时间 | **证据**——全量保底永不删除；快通道同步落袋对象 |
| 语义原子 MemoryEntry | 记忆条目：{主体,谓词,客体}+双时态（valid_from/valid_to+learned_at）+supersedes+引文 span+类型+置信+来源 S1-S4+视野+强度 | **资产**——可校验/可更新/可消解/可预算择优的最小记忆单位 |
| 模式原子 PatternAtom | S4 派生的模式陈述（跨期计数+血缘回连） | 压缩产物；"本月提到记忆 17 次" |
| 关联边 AssociationEdge | 八类边：实体/时序/情境/替代/语义/因果/派生/冲突；权重+置信+依据+双时态 | 无依据不建边；血缘=type='derived'；边可见性=min(两端点) |
| 引文锚点 AnchorSpan | 断言在原文中的 span 定位 | 无引文不记忆的执行载体；{memory_id, span} 溯源 |
| 来源级别 SourceLevel | S1 用户明示 / S2 对话推断 / S3 导入 / S4 二次推理 | 置信三因子之一；与交付切片 Slice（S0-S3）同形异义，词典分立 |
| 置信 Confidence | 来源权重 × 抽取分 × e^(-λ·Δt)；自报分经校准集映射；不采流畅度信号 | 低置信隔离谓词的输入；读取结果透出"明确说过 vs 我推测" |
| 强度 Strength | f(重复,检索,情感) × e^(-λ·Δt)；Δt 于检索命中重置（再巩固窗口） | 融合排序加权项；灰色遗忘=降权 |
| 单元切分 Segmentation | 写侧第一决策：从连续流发现记忆单元（对话轮/文档段/事件），统计信号可归因，span 保底可逆 | segment 步骤产物=segments 表；切分参数是演化参数（约束 13） |

## 3. 意图与网络

| 概念 | 定义 | 与其他概念的关系 |
|---|---|---|
| 意图 Intent | 唯一"有时效、可交易、需确认"的记忆——"未来的事"；核心层只有字段与状态机位 | 双入口：声明直生效 / Agent 只产候选；全网确认链只有一条 |
| 三旋钮 | 有效期 / 可见性滑杆 / 期望回应 | 每档可见性是一次视野变更 |
| 意图发现位 DiscoverySlot | "生效中意图进入发现网络的位数"——配额口径（G3）：免费 3 个，Pro 不限；意图本体永远免费不限量 | 计费维度，非意图数量 |
| 公开条目 PublishedItem | 发布投影：L4 抽象（生成/发布分离）与 L5 主动公开 | 派生不越权的唯一合法例外；72h 无痕撤回窗 |
| 目的闸 PurposeGate | 公开面检索按"允许目的集 × 声明目的"匹配放行 | 裁决器谓词；不匹配不入结果集 |
| 认知简报 Brief | 晨报/周刊：业务层对 search 的定时消费+渲染送达；核心层零简报语义 | "没意识到的"栏目硬编码伦理过滤（禁区②） |
| 撮合 Matching | 检索即撮合：无撮合专属 API，全部经 add/search 消费 | 偏好出域只走 L4 抽象通道 |

## 4. 质量与治理

| 概念 | 定义 | 与其他概念的关系 |
|---|---|---|
| 弃权 Abstain | 自动裁决链任一级"判不了"的一等合法结论：显式原因码+挂 pipeline_review_queue 人裁 | 禁默认值兜底（约束 15，Turing 上界）；score 四态之一 |
| 四态路由 FourWayRoute | 提取 / 折叠 / 留原文 / abstain | 写入时首次压缩决策 |
| 巩固收益门 ConsolidationGate | 固化入结构化层必须携带泛化收益量化信号：复用频次 × 跨情境度 × holdout 增益 | 防过拟合（R1）；schema 级抽象过严格门（R9） |
| 再巩固窗口 ReconsolidationWindow | 检索命中后 72h 内允许 supersedes 重写与衰减重置 | 窗口外写入走派生门禁（约束 11/R2） |
| 双指标 DualMetrics | 存储完备率（写侧）与检索召回率（读侧基准对账）分设阈值分开报警 | 未检索 ≠ 未存储（R3）；不得互相伪装 |
| 血缘回溯 LineageRecompute | 纠错沿派生链 BFS 下游 stale 重算 | 错误不扩散；recompute 管道 |
| 记忆体检 HealthScan | 周任务扫低置信/真矛盾/长期未验证 → 待确认清单 | 随周刊推送 |

## 5. 工程概念（框架层）

| 概念 | 定义 | 与其他概念的关系 |
|---|---|---|
| 处理容器 ProcessingContainer | 方法执行模型：五参五段执行（提取→封装→操作→拍平→异常策略） | 统一签名的运行时（A9）；业务只写"操作"段 |
| 数据契约 DataContract | 步骤/模型间传版本化 JSON 文档，JSONPath 映射抽取，合同测试进 CI | 不传对象不 import 类型（A6） |
| 流程图 Pipeline | 版本化有向图定义（六型节点+条件边），数据而非代码 | 编译期五关校验；default 禁直连成功终态 |
| 任务 Task | 受理面的执行实例：202+task_id，检查点游标=活跃节点集 | 入队与业务写入同事务；租约+调用缓存崩溃恢复 |
| Store 槽位 StoreSlot | 外部组件接口族 9 槽位（Data/Vector/FullText/Graph/TaskQueue/Cache/Lock/Object/PubSub） | 部署档位=槽位预设；允许缺失降级（A10） |
| 防腐层 AntiCorruptionLayer | 一切外部组件唯一访问点：协议翻译/容错/降级/打点 | 业务禁 import 外部 SDK（A11） |
| 快通道 FastPath | 接入事务内同步直写原文层，零 LLM，<100ms 可检索 | 任务式受理的质量兜底预期 |
| 交付切片 Slice | S0 保底档 / S1 理解闭环 / S2 信任完整 / S3 网络与开发者面 | 与来源级别 SourceLevel（S1-S4）同形异义，词典分立 |
| 202 受理语义 AcceptSemantics | 同步受理返回 task_id+SSE 订阅地址；原文已落袋+快通道可检索 | 受理响应必须携带"已记住"的确认语义（Mem0 对比①） |
